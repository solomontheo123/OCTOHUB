### Problem 1

Accidentally initialized Django project inside home directory (`~`) instead of backend folder.

### Solution

* Removed accidental Django files
* Deleted old workspace
* Recreated clean OCTOHUB structure

### Lesson Learned

Always verify current directory using:

```bash
pwd
```

before running important commands.
